# UX Profile

Written 24 Oct 2026 from the console as it is (`src/web/public/index.html`) and what the
people using it asked for. All UI/UX skills in this project read this file before
changing layout, copy, or interaction. Edit it directly to change a default.

## Aesthetic reference

- **Standard:** Custom <!-- Linear | Stripe | Apple Native | Raycast | Notion | Custom -->
- **Notes:** masterapp's own look, kept on every page — not a new one per page. Warm paper
  canvas (`--paper #f6f3ee`), white panels (`--card`) with a 1px `--line` border and the
  soft `--shadow`, ink `#1d1b18`, muted `#6f685d`. One accent: gold `#8a6a2f` (links,
  active tab, primary buttons). Status colours only for status: good green, warn amber,
  bad red, blue for "moving". EB Garamond (`--serif`) for page titles and big figures only;
  Hanken Grotesk (`--sans`) for everything else. Radius 10px on panels. Density: Stripe-like —
  readable rows, calm whitespace. Users: a small watch-dealing team in Pakistan and Dubai,
  not technical, English not their first language — every screen must be obvious at a
  glance ("easy to understand even for a dumb person", asked 24 Oct 2026).

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata (a chip is for a status or a filter)
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Raw technical text in the interface: field keys (`fedexUpdatedAt`), epoch milliseconds,
  ids, "null", empty arrows (`→ —`)

## Accessibility target

- **Level:** WCAG 2.1 AA <!-- WCAG 2.1 AAA | WCAG 2.1 AA -->
- **Contrast:** 4.5:1 for normal text, 3:1 for large text and borders.
- **Touch / focus:** 44×44px targets; visible `:focus-visible` ring. Used on phones in the
  field — prove 375px.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal <!-- Utilitarian & Minimal | Warm & Humancentric | Opinionated & Direct -->
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain, short, everyday English words — for readers whose first language is not
  English. Say what a thing is in the business's words (watch, stock number, client,
  shipment, polish), never the system's. Numbers carry their currency (`AED 1,200`). Dates
  as "24 Oct 2026".

## Icon library

- **Library:** None <!-- Lucide | Heroicons | Phosphor | Tabler | Radix Icons | Remix Icon | Project SVG | None -->
- **Package / path:** —
- **Notes:** No build step and scripts only from the app itself (CSP), so no icon package.
  Text labels first; a small inline SVG only where a mark is conventional. No emoji as icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
